# Difference Between JPA, Hibernate, and Spring Data JPA

## JPA (Java Persistence API)

JPA (Java Persistence API) is a specification, which means it only provides a set of rules and guidelines for storing Java objects in a relational database. It defines how Java classes should be mapped to database tables using annotations such as `@Entity` and `@Id`. However, JPA itself cannot perform database operations because it is not a framework. It always requires an implementation, such as Hibernate, to execute operations like saving, updating, deleting, and retrieving data.

## Hibernate

Hibernate is an ORM (Object Relational Mapping) framework that implements the JPA specification. It follows all the rules defined by JPA and performs the actual database operations. Hibernate automatically converts Java objects into database records and vice versa, so developers don't need to write SQL queries for every operation. It also provides additional features like automatic SQL generation, caching, lazy loading, and transaction management, making database interaction much easier and more efficient.

## Spring Data JPA

Spring Data JPA is a part of the Spring Framework that is built on top of JPA. It simplifies database development by providing ready-made repository interfaces such as `JpaRepository`. Instead of writing separate DAO classes and SQL queries for common operations, developers can directly use methods like `save()`, `findAll()`, `findById()`, and `deleteById()`. By default, Spring Data JPA uses Hibernate as its JPA implementation, which reduces boilerplate code and speeds up application development.

## Difference Between Them

The main difference is that **JPA is only a specification**, **Hibernate is the framework that implements those specifications**, and **Spring Data JPA is a Spring module that makes working with JPA much easier**.

JPA only defines the standards for database persistence and cannot perform any database operations on its own. Hibernate follows these standards and performs the actual CRUD operations while also providing many advanced features. Spring Data JPA sits on top of JPA and Hibernate, offering built-in repository methods that eliminate the need to write repetitive database code.

### Summary

* **JPA** defines the rules for database persistence but does not perform any operations.
* **Hibernate** implements JPA and handles the actual communication with the database.
* **Spring Data JPA** simplifies database development by providing ready-made repository methods and using Hibernate behind the scenes.

In simple words, **JPA tells what should be done, Hibernate does it, and Spring Data JPA makes it easier for developers to use Hibernate with minimal code.**
